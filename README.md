# Alton Testnet

Alton Testnet — DeFi приложение с Telegram Mini App интерфейсом для работы с брендовыми токенами, пулами ликвидности и BrandPad.

## 🗂 Структура проекта Alton Testnet

### Корневые директории

- `/backend` — серверная часть приложения на NestJS с GraphQL API и PostgreSQL
- `/frontend` — клиентская часть на React с интеграцией Telegram Mini App
- `/whitepaper` — документация, спецификации и технические описания

---

### 📦 Структура бэкенда (`/backend`)

#### Основные директории:

- `/src` — исходный код приложения
- `/common` — общие компоненты
- `/constants` — константы проекта (коды ошибок, статусы и т.д.)
- `/decorators` — кастомные декораторы NestJS
- `/filters` — фильтры исключений
- `/guards` — защитники доступа
- `/interfaces` — общие интерфейсы
- `/pipes` — трансформаторы и валидаторы данных
- `/utils` — утилиты
- `/config` — конфигурации и переменные окружения

#### Модули (`/modules`):

Каждый модуль имеет собственную структуру:

- `/contract` — управление смарт-контрактами
- `/pool` — управление пулами ликвидности
- `/brand` — управление брендами и токенами
- `/brandpad` — управление запуском брендовых токенов
- `/analytics` — аналитика и графики

Структура внутри каждого модуля:

- `/dto` — объекты передачи данных
- `/entities` — сущности базы данных
- `/interfaces` — интерфейсы модуля
- `/repositories` — взаимодействие с БД
- `/resolvers` — GraphQL резолверы
- `/services` — бизнес-логика

#### Индексер (`/indexer`):

- `/adapters` — адаптеры к источникам данных
- `/services` — сервисы индексирования
- `/database` — работа с БД
- `/migrations` — миграции схемы БД
- `/seeds` — начальные данные
- `/entities` — общие сущности
- `/graphql` — конфигурация GraphQL
- `/schema.gql` — автогенерируемая GraphQL-схема
- `/scalars` — пользовательские скалярные типы

---

### 🖥️ Структура фронтенда (`/frontend`)

- `/src` — основной код приложения
- `/components` — UI-компоненты (React)
- `/pages` — страницы приложения

- `/utils` — вспомогательные функции
- `/styles` — темы и стили
- `/types` — глобальные типы TypeScript

- `/graphql` — запросы и типы для GraphQL
- `/telegram` — интеграция с Telegram Mini Apps
- `/assets` — статические ресурсы (изображения, шрифты и т.д.)

```bash

```

```bash
cd frontend
npm install
npm run dev
```

## Технологический стек

### Бэкенд
- Node.js (NestJS)
- GraphQL
- PostgreSQL (TypeORM)
- Indexer для синхронизации с блокчейном

### Фронтенд
- React
- Telegram Mini Apps SDK
- Apollo Client для GraphQL
- Styled Components

## Структура бэкенда

- Модульная архитектура с чётким разделением слоёв
- GraphQL API с типизированными схемами
- Индексер для синхронизации данных с блокчейном
- Репозитории для работы с базой данных
- Сервисы с бизнес-логикой
- Резолверы для GraphQL API

## Модули

- `Contract` - управление контрактами
- `Pool` - управление пулами ликвидности
- `Brand` - управление брендами и брендовыми токенами
- `BrandPad` - управление платформой для запуска брендовых токенов
- `Analytics` - аналитика и графики

## Индексер

Система индексации данных из блокчейна с регулярным обновлением состояния контрактов, пулов и брендов в базе данных.

# Alton Project

## Структура репозиториев

Проект состоит из трех Git репозиториев:

1. **Основной репозиторий** - содержит общие файлы проекта, документацию и конфигурацию Docker
2. **Frontend репозиторий** - содержит код фронтенда 
3. **Backend репозиторий** - содержит код бэкенда

## Клонирование репозитория

```bash
# Клонирование основного репозитория
git clone <url-основного-репозитория> alton-project
cd alton-project

# Инициализация и обновление подмодулей
git submodule update --init --recursive
```

## Работа с репозиториями

### Основной репозиторий

Содержит общие файлы проекта, настройки Docker, документацию.

```bash
# Пример работы с основным репозиторием
git add README.md
git commit -m "Обновление документации"
git push
```

### Frontend репозиторий

```bash

# Внесение изменений
# ...

# Коммит и публикация изменений
git add .
```

### Backend репозиторий
